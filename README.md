# Ежедневный дайджест контент-плана в Telegram

Скрипт `telegram_daily.py` каждое утро в 08:00 по Москве читает три листа
таблицы (ЯМАЛМОТО, Геохакинг, Дома скучно), находит строки с сегодняшней
датой в колонке A и шлёт в Telegram сообщение со всем, что запланировано
на сегодня — включая дни, где несколько роликов/сторис в одном аккаунте.

Важно: облачная среда, в которой я работаю, не может напрямую стучаться в
Telegram API (сетевые ограничения), поэтому сам бот работать 24/7 отсюда
не может. Решение — бесплатный и надёжный вариант: GitHub Actions запускает
скрипт по расписанию. Настройка займёт 5 минут.

## Настройка

1. Создайте новый репозиторий на GitHub (можно приватный).
2. Загрузите в него файлы `telegram_daily.py` и `.github/workflows/daily-report.yml`
   (сохранив структуру папок).
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**
   и добавьте два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен вашего бота от @BotFather
   - `TELEGRAM_CHAT_ID` — id чата/канала, куда слать сообщения (см. ниже, как узнать)
4. Проверьте вручную: вкладка **Actions → Daily content digest to Telegram → Run workflow**.
   Если всё настроено верно, сообщение придёт сразу.
5. Дальше скрипт будет запускаться автоматически каждый день в 08:00 МСК.

GitHub отключает cron-расписание, если в репозитории 60 дней не было ни одного
коммита — если это разовый проект без активности, иногда делайте пустой коммит.

## Как узнать chat_id

- Для группы: добавьте бота в группу, напишите любое сообщение, затем откройте
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — там будет `"chat":{"id": -100...}`.
- Для публичного канала: chat_id — это `@username_канала` (бот должен быть админом канала).

## Токен бота

Токен, который вы прислали в чат, был показан в открытом виде — если это
рабочий бот, рекомендую на всякий случай перевыпустить токен через
@BotFather → `/mybots` → выбрать бота → API Token → Revoke.
